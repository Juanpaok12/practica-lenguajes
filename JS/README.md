# Práctica de lenguajes de programación

Repositorio donde guardo los ejercicios y proyectos pequeños que hago mientras estudio el Tecnólogo en Análisis y Desarrollo de Software en el SENA (modalidad virtual).

## Estructura

| Carpeta | Contenido |
|---|---|
| `Java` | Ejercicios básicos: estructuras de control, variables |
| `JS` | Ejercicios de JavaScript (`semana1.js`) |
| `proyecto-boton` | Página web que consulta el dólar en pesos colombianos |
| `C`, `C++`, `C#` | Primeros programas "Hola mundo" |
| `Python`, `PHP`, `HTML` | Primeros programas y prácticas |

## Proyecto destacado

**[Dólar hoy en Colombia](proyecto-boton)**: página con HTML y JavaScript que usa `fetch` para consultar una API pública y muestra el precio del dólar al hacer clic en un botón.

## Cómo ejecutar los ejercicios de JavaScript

1. Instala [Node.js](https://nodejs.org).
2. En la terminal, desde la raíz del repositorio:

   node JS/semana1.js
