# Dólar hoy en Colombia

Página web que muestra el precio actual del dólar en pesos colombianos al hacer clic en un botón.

## Tecnologías
- HTML
- JavaScript (fetch y eventos)
- API pública Frankfurter

## Cómo ejecutarlo
1. Descarga o clona el repositorio.
2. Abre `index.html` con Live Server o en el navegador.
3. Haz clic en "Consultar dólar".

## Qué aprendí
- Consumir una API con `fetch`.
- Manejar el evento de clic y los errores con `.catch`.
- Subir cambios con Git y GitHub.
